# Smart Electricity Consumption and Bill Analysis System

## Project Description
The Smart Electricity Consumption and Bill Analysis System is a Java web application developed to manage customer information, record electricity readings, and calculate electricity bills.

## Technologies Used
- Java
- JSP and Servlets
- JDBC
- MySQL
- Apache NetBeans
- Apache Tomcat 11
- Maven

## Features
- Customer record management
- Electricity reading entry
- Automatic unit calculation
- Electricity bill calculation
- MySQL database connectivity
- Display of electricity records and bills

## How to Run
1. Open the project in Apache NetBeans.
2. Configure the MySQL database.
3. Update the database connection settings.
4. Add the required MySQL Connector/J dependency.
5. Configure Apache Tomcat 11.
6. Run the project from NetBeans.

## Database
Create the required database and tables in MySQL before running the application. Import the project's SQL script if one is included.
